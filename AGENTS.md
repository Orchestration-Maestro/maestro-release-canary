# AGENTS.md

`release-canary` is a deliberately small Rust binary. Its only job is to prove,
on real tags, that `rust-workflows` releases what it claims: every push runs
the organization's Rust CI, and every `v*` tag runs the live release path.

## Rules

- **Keep it small.** `checked_sum` and its one dependency, `anyhow`, exist so
  the dependency policy, the SBOMs and the embedded dependency list describe
  something real. Add code only when the release path has a new case to prove.
- **Managed files belong to `rust-gate sync`.** The CI caller, the hooks, the
  lint table in `Cargo.toml` and the configuration files carry a `generated by
  rust-gate` marker, and the organization's quality sync rewrites them. Change
  their source in `rust-workflows`, never the copy here.
- **Releases are protected.** A `vX.Y.Z` tag on `main`, an existing GitHub
  Release and two approved `release` deployments: README's "Cutting a
  release".
- **Commits** are signed, with conventional titles; `main` takes only
  squash-merged pull requests.

## Verify before committing

```bash
cargo fmt --all --check
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test --workspace --locked
prek run --all-files
```

Done when every command passes.
